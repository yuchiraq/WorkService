# Document Fonts

Unmodified Liberation Serif 2.1.5 (Regular, Bold, Italic), SIL Open Font License 1.1.

Upstream: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5

Archive linked by that release:
https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz

The license and author notices are preserved in LICENSE and AUTHORS. Font files
remain embedded for portable renderer tests and old cached editor assets. New
PDF exports require an installed, appropriately licensed Times New Roman font
and never silently substitute these OFL fonts. See `times.go` and
`docs/construction-documents.md` for deployment configuration.
